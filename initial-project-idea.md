# Initial project idea

Date: 2026-10-06

## Context
Considering a project with a higher chance of success than the current trade-skills page. Success means one of: an internship offer, a working tool someone actually uses, or passing NCI modules. Existing projects are Forget and The Ledger Lands. Starting a third project would split focus, so the preference is to finish or reshape existing work rather than add new work.

## Options considered

1. **Reconciliation and variance pack (recommended)**
   - A small SQL and Excel project that reconciles two sets of sample transactions (for example, a bank feed against a ledger) and flags differences.
   - Includes a one-page summary of findings.
   - Fits: draws on AIA reconciliation work, builds the SQL being learned now, matches what Dublin finance internship interviewers ask about.
   - Likely to succeed: small enough to finish in a few weeks, explainable in two sentences, clear finish line (runs, on GitHub, can be walked through).
   - Risk: uses sample data, so it can look generic unless the business problem is explained.

2. **Finish Forget as a single-user tool**
   - Stop adding features, make the current version reliable, write a short case study.
   - Fits: used daily, already built, so finishing is cheaper than starting.
   - Risk: harder to show employers the value of a personal tool; does not directly build the finance story.

3. **Ship The Ledger Lands as a public game**
   - Most original and most visible.
   - Risk: highest. Needs art, testing, feedback and an audience. An unfinished game has no value to employers.

## Recommendation
Option 1, scoped down. Use it to replace The Ledger Lands for now, and keep Forget on maintenance. Build the reconciliation pack in SQL with a short Excel summary. Set a four-week finish line, then use it in applications and interviews.

## Open decisions
- Which single outcome to optimise for: an internship, or a tool people use.
- How many hours per week can be given to it.
